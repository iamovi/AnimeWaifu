Available Apps

  • AnimeWaifu: Main AnimeWaifu application for Windows and Android.
  • AnimeWaifu Basic: Basic version of the main application, Just swipe and waifu image without Chatrooms and other feature.
  • AnimeWaifu Lite: Lightweight version of the main application.
  • AnimeWaifu Cloud: Cloud Based App to run All AnimeWaifu Versions.
  • AnimeWaifu QuickChat: A dedicated quick chat app from main App.

Other Ways to Download

PowerShell Installation (Windows)

Run PowerShell as administrator and type this command:

powershell -c "irm iamovi.github.io/AnimeWaifu/Install.ps1 | iex"
  • Choose which version to download
  • Wait for the installation to complete

Node.js CLI Installation (Windows)

Install CLI globally using NPM:

npm i animewaifu_app_installer -g

Run the CLI:

animewaifu-installer

Follow instructions to install AnimeWaifu App!

Projects

AnimeWaifu Pixel Terminal

This is a CLI tool that brings Anime Waifu straight to your terminal! Fetch a new waifu every time you run it and display it in pixel style.

📦 Installation and Usage

npm i -g animewaifu_pixel_terminal
aw

Type aw to view a AnimeWaifu on terminal.

SysWaifu 🌸

A Cross-Platform aesthetic system information fetcher with a waifu touch — inspired by tools like neofetch, but cuter. Displays your system info alongside a randomly fetched waifu image directly in the terminal.

📦 Installation and Usage

npm install -g syswaifu
syswaifu

ℹ️ Information Displayed

  • System: OS, Kernel, Uptime, Hostname, Installed Packages
  • Hardware: CPU, Cores, Clock Speed, GPU
  • Memory: RAM Usage, Disk Usage
  • Power: Battery Status (for laptops)
  • Display: Screen Resolution
  • Network: WiFi Connection

🖥️ Cross-Platform Support

Works on Windows, macOS, and Linux with platform-specific optimizations.

About AnimeWaifu Project

What is AnimeWaifu?

AnimeWaifu is a collection of applications and tools designed for anime enthusiasts. The project brings anime waifus to your desktop and mobile devices through various applications, from simple image viewers to interactive chat experiences.

Project Goals

The AnimeWaifu project aims to create fun, engaging, and accessible applications that celebrate anime culture. Whether you want a quick waifu image, system information with style, or interactive features, AnimeWaifu has something for everyone.

Open Source

All AnimeWaifu projects are open source and available on GitHub. We believe in community-driven development and welcome contributions from developers and anime fans alike.
