**So, Basically this project is made to install AnimeWaifu Windows Apps using Terminal, A Easy Solution.**

## Installation and Usages

```bash
npm i animewaifu_app_installer -g
```

#### Then

```bash
animewaifu-installer
```

> Open Terminal as an administrator to Install any version of AnimeWaifu App.
