#### This is a CLI tool that brings Anime Waifu straight to your terminal! Fetch a new waifu every time you run it and display it in pixel style.

***This is a side project of main [AnimeWaifu](https://github.com/iamovi/AnimeWaifu) project.***

***Visit: [https://github.com/iamovi/AnimeWaifu](https://github.com/iamovi/AnimeWaifu).***

## 📦 Installation and Usages

```bash
npm i -g animewaifu_pixel_terminal
```

```bash
aw
```
Type **aw** to view a random AnimeWaifu image on terminal.
